# 普通登录弹窗自动恢复验收

日期：2026-11-04；版本：2.1.1；Windows / Microsoft Edge。

## 问题与处理

“WTT赛事”双平台任务曾在抖音普通登录提示处暂停。旧逻辑检测到弹窗后立即枚举关闭按钮，没有等待按钮挂载；关闭后仅固定等待350毫秒，也没有确认弹窗消失。原失败未能稳定复现，因此不能确定当时是按钮延迟还是页面变体。

新版等待可点击的正常关闭控件（默认最多3秒），点击后等待弹窗消失（最多2秒）。加入已观测的抖音登录标题栏结构作为哈希类名变更的后备定位；小红书使用现有关闭按钮。对关闭成功才计数，每次检查最多关闭两次；仍持续出现或控件无效时保留断点。透明祖先中的隐藏内容不再当作可见弹窗，固定定位内容仍可通过零尺寸宿主识别。

## 本机验证

`npm test`：28项通过。新增真实浏览器离线用例覆盖按钮延迟挂载、关闭延迟生效、透明祖先、抖音类名变更、无关闭控件及点击无效；原有零尺寸宿主、验证码保护用例通过。

## 平台实测

使用采集工作台专用浏览器资料，未进行账号登录。测试通过平台正常按钮打开抖音登录弹窗；小红书页面自行显示登录弹窗。随后交给采集程序处理，全程无人工关闭操作。

| 平台 | 连续查询词 | 结果 |
| --- | --- | --- |
| 抖音 | wtt赛事最新消息、wtt赛事赛程、WTT赛事规则 | 自动关闭1次登录弹窗，3次查询各返回10个真实下拉词 |
| 小红书 | WTT赛事、WTT赛事规则、WTT赛事赛程 | 自动关闭1次登录弹窗，3次查询各返回10个真实下拉词 |

本轮仅为浏览器适配验收，诊断查询不写入用户任务断点，不将6次查询称作三层完整遍历。平台返回词会动态变化。

普通登录提示由程序自动处理。实际安全验证、强制登录或访问限制仍保留断点等待处理；本次实测不能证明平台未来永远不触发这些状态。
