# 任务编辑与双平台并发验收

日期：2026-11-04；版本：2.3.0；Windows / Microsoft Edge。

## 交付行为

- 任务详情和采集记录均提供编辑入口。任务停止后可修改查询间隔；已有结果时可以增加层数，保留原结果并继续展开边界词。
- 尚无成功查询的任务可修改起始词、平台和层数。已有结果的起始词及平台保持不变；减少层数或更换采集对象需新建任务。
- GUI、CLI、PowerShell启动脚本及核心遍历均移除查询次数上限。旧任务加载时自动清理原测试限制，暂停任务保持暂停。
- 双平台各开专用浏览器、各自按间隔依次查询；跨平台并发。断点、图更新和导出串行提交。
- 暂停时等待两侧在途查询完成并保留成功结果。一侧出现访问问题时停止启动新词，另一侧在途成功仍保存，然后进入原有人工处理流程。
