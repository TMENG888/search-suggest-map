# 开发说明

## 模块

| 模块                   | 职责                                                             |
| ---------------------- | ---------------------------------------------------------------- |
| `server.mjs`           | 本机HTTP服务、静态界面、SSE事件、任务接口、文件与ZIP导出         |
| `jobs.mjs`             | 任务生命周期、目录、锁、浏览器会话、人工确认、历史恢复           |
| `public/`              | 无构建步骤的原生HTML/CSS/JS工作台，实时SVG树与表格               |
| `browser.mjs`          | Playwright平台适配、普通登录弹窗关闭、真实下拉提取及访问限制判断 |
| `core.mjs`             | 广度优先遍历、规范化去重、跨分支关系、断点和离线导出             |
| `audit.mjs`            | 完成时校验节点、回执、关系及原始下拉排序                         |
| `mindmap-template.mjs` | 独立可离线使用的交互思维导图                                     |
| `collect.mjs`          | 保留的命令行入口                                                 |

## 任务状态

```text
ready → running → complete
            ├── awaiting_verification / awaiting_browser
            │      ├── 人工点击继续 → running（同一浏览器）
            │      └── 点击暂停 → pausing → paused
            ├── 点击暂停 → pausing → paused
            └── 未确认结果 / 查询上限 → paused
paused / error → 用户继续 → running
```

每个成功查询先写断点，再更新导出和通知。`complete`须通过完整性核验。查询失败时保留为待查询；不能以空数组替代失败。服务异常退出后，`querying`节点恢复为`pending`，不会重跑已完成节点。

人工验证没有定时重试：保存浏览器对象并等待界面确认。用户继续后复用该对象，因此不会因为关闭浏览器丢失刚完成验证的会话。用户暂停或服务退出则保存并关闭。

## 数据与互斥

图的键是“平台 + NFKC规范化后的词”。广度优先遍历保证最小发现深度；树使用首次父词，完整关系另存。边界层仅保存，不再查询。

GUI全局只允许一个任务或一个平台登录会话，工作目录有服务PID锁，每个任务另有运行锁。读取旧锁时先验证PID是否仍存活，不自动删除活跃进程的锁。不要将两个GUI或CLI同时指向同一浏览器资料目录。

默认数据在代码目录外。`.gitignore`不允许上传常见运行目录、Cookie、环境配置及依赖。导出白名单只包含结果文件，不读取浏览器资料。

## 本机接口

- `GET /api/bootstrap`：会话令牌、任务摘要与运行目录。
- `GET /api/events`：SSE更新通知，客户端随后读取当前任务。
- `POST /api/jobs`：创建任务。
- `GET /api/jobs/:id`：任务详情与图数据。
- `POST /api/jobs/:id/start|pause|continue`：生命周期操作。
- `POST /api/import`：校验并导入JSON检查点或完整结果。
- `POST /api/browser/open|close`：准备登录会话。
- `GET /api/jobs/:id/download.zip`：稳定状态的完整结果包。
- `GET /api/jobs/:id/files/:file`：白名单文件。

只监听`127.0.0.1`，Host白名单防止DNS重绑定；修改请求同时校验同源Origin和随机会话令牌，不开放CORS。不要直接反向代理到公网；本项目没有多人鉴权或云端浏览器隔离。

## UI设计

- 白色底面、蓝色主操作`#2258ca`、正文`#202e48`、细线`#e3e9f2`、淡蓝画布`#fbfcff`、完成绿`#187d68`。
- Segoe UI Variable与微软雅黑；文字层级服务于任务配置、图的可读性和状态判断。
- 左侧输入与历史，中间真实联想关系，右侧当前节点与运行动态；缩小到手机宽度后顺序排列。
- 不把登录资料、选择器或模型等实现细节放入主要用户操作；真实平台限制必须明确显示。

## 验证范围

单元和界面测试中的平台提供器为离线测试实现。生产界面没有模拟采集入口，平台结果只能来自`BrowserProvider`。真实平台验收另有回执，小红书已完成未登录两层采集，不能把离线测试数据当作平台实采数据。

真实平台验收沿用输出目录中的原始回执和`完整性核验.json`；平台更换选择器后需重新执行线上小样本。已完成真实数据可通过GUI导入检查大图的展开、搜索和导出，无需再次批量查询。
